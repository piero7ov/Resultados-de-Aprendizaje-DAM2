# Producto en Marcha — Planteamiento

## Idea

Crear una demostración multimedia interactiva del recorrido de un producto por varias estaciones de trabajo. El usuario podrá observar qué sucede en cada estación y realizar pequeñas acciones para avanzar. El proceso será simulado.

## Recorrido previsto

1. **Recepción:** llega el producto y se comprueba su identificación.
2. **Control de calidad:** se inspecciona y se decide si puede continuar.
3. **Embalaje:** se protege, se introduce en una caja y se cierra.
4. **Expedición:** se verifica el paquete y se registra su salida.

Cada estación tendrá una descripción breve, una cinta que conecte el recorrido y una persona representada de forma esquemática con un chaleco de color diferente.
