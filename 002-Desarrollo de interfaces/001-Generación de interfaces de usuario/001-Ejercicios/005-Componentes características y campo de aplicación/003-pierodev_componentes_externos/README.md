# Componentes externos de ERIN

Esta iteración separa la estructura, el estilo, la lógica, los datos y los templates de la interfaz.

## Estructura

- `index.html`: estructura principal y punto de entrada.
- `css/estilo.css`: identidad visual y distribución de ERIN.
- `js/componentes.js`: carga y generación de los componentes.
- `data/`: orígenes JSON para la navegación, las entidades y la tabla.
- `templates/`: plantillas HTML reutilizables.

## Ejecución

El proyecto debe abrirse mediante Apache para que las peticiones `fetch()` puedan cargar los archivos locales.

La página de entrada es `index.html`.
