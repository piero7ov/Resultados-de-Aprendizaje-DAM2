Eventos en un campo input

Los campos de texto pueden responder a acciones como recibir el foco, perderlo, cambiar su contenido o detectar las teclas pulsadas.

1. Seleccionar un campo de texto

Para trabajar con un <input> desde JavaScript, primero se selecciona y se guarda en una variable.

Si el elemento es un <input>, conviene utilizar un nombre como entrada y no conservar por error la variable boton de un ejercicio anterior.

2. Evento onfocus

onfocus se ejecuta cuando el campo recibe el foco. Esto ocurre, por ejemplo, al pulsar dentro de él o al llegar mediante el tabulador.

3. Evento onblur

onblur se ejecuta cuando el campo pierde el foco. Es necesario entrar primero en el campo y después pulsar fuera de él.

4. Evento onchange

onchange se activa cuando el valor ha cambiado y el campo confirma ese cambio, normalmente al perder el foco.

5. Evento onkeypress

onkeypress se ejecuta al introducir una tecla que genera un carácter. El manejador recibe un objeto de evento con información sobre la tecla pulsada.

En este ejemplo se consulta evento.key para mostrar el carácter y también se envía el objeto completo a la consola.

6. Todos los eventos en un mismo input

Este campo combina los cuatro eventos. El mensaje indica cuál ha sido la última acción detectada.

Para comprobar onchange, modifica el texto y pulsa fuera del campo. Según la acción, pueden ejecutarse varios eventos seguidos.
