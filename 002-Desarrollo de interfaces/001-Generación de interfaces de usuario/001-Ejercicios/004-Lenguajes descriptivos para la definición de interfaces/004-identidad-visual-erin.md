# Identidad visual de ERIN

- **Especialización:** CRM y ERP, nuestras soluciones de gestión más completas, identificadas con el color salmón.
- **Identidad adaptable:** letra destacada y color según el ámbito del software.
- **Logo:** punto del mismo color que la letra destacada.
- **Selección:** punto y línea con el color de identidad.
- **Botones:** acabado metálico.
- **Bordes:** dos esquinas opuestas redondeadas y dos rectas.
- **Tipografía:** Coolvetica como fuente de identidad.
- **Interacción:** resaltado y extensión suave hacia el borde.
