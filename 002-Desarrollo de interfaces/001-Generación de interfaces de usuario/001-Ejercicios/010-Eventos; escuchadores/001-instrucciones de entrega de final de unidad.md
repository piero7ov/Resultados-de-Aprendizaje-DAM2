# Entrega final de la unidad

El proyecto final se llama **ERIN IU** y contiene un diseño propio de interfaz de usuario.

La entrega se organizará en tres carpetas:

1. `Ejercicios`
2. `Proyecto`
3. `Resultado de Aprendizaje`

ERIN IU ya aporta evidencias de los criterios de evaluación: emplea herramientas de interfaz, organiza componentes, adapta sus propiedades, modifica el código generado, asocia acciones a eventos y forma una aplicación funcional.
