# Requisitos del sistema

El sistema de gestión empresarial utilizará las siguientes tecnologías:

- Frontend: HTML, CSS y JavaScript. Al ser contenido estático, podrá ejecutarse en un servidor web compatible.
- Backend: PHP para ofrecer una API que separe la interfaz de la capa de datos.
- Almacenamiento: SQLite, MySQL, MongoDB o una solución personalizada.

Para alojar el sistema se pueden considerar estas opciones:

- Hosting compartido: suele proporcionar un entorno LAMP formado por Linux, Apache, MySQL y PHP.
- VPS: permite instalar otros sistemas y ofrece mayor libertad de configuración.

La elección dependerá de las necesidades actuales y futuras del proyecto.
